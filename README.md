# Security Operations (SOC) & Control Validation

Welcome to the Security Operations branch of my portfolio. This repository contains hands-on technical projects demonstrating my ability to secure enterprise environments, execute technical remediations, and validate security controls at the operating system and network levels.

## Branch Objective
To showcase practical, command-line-driven engineering skills. The projects here focus on the "how" of cybersecurity: actively patching vulnerabilities, configuring secure protocols, and hardening systems against active exploitation.

## Core Competencies Demonstrated
*   **System Hardening:** Applying Security Technical Implementation Guides (STIGs) to Windows Server environments.
*   **Vulnerability Remediation:** Executing PowerShell scripts to enforce secure network protocols (SMB Signing, NLA, LAN Manager Authentication).
*   **Patch Management:** Managing OS cumulative updates and updating antimalware definitions.
*   **Identity & Access Management (IAM):** Auditing and revoking unauthorized local administrative privileges.
*   **Control Validation:** Utilizing Tenable Nessus authenticated scans to mathematically verify that technical remediations successfully mitigated targeted CVEs.
